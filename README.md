# Experiment
A Dart Monkey, or is it?

A custom BTD6 Military tower created with BTD6 Mod Helper.

Experiment was created in an underground laboratory to exceed normal monkey limits.

## Features

- 15 custom upgrades
- 3 complete upgrade paths
- Custom transformation mechanics
- Singularity attack-speed stacking
- Army/support mechanics
- Precision path
- Custom Paragon: The Final Experiment
- Paragon degree scaling

## Requirements

- Bloons TD 6
- MelonLoader
- BTD6 Mod Helper

## Version

1.0.0
